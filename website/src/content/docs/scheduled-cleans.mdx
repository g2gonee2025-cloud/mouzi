The scheduler runs at selected local times while Mouzi is running. Each run adds an extra pass over files already in eligible watched folders.

## Configure a schedule

Open **Settings → General** and scroll to **Scheduler**. Turn on **Enable scheduled organization**, choose one to four times per day and select **Save**. Times use the computer's local clock.

Mouzi checks the schedule approximately once a minute. A run may therefore begin shortly after the displayed minute rather than at the exact second.

## Which folders run

Scheduled runs check enabled **Silent** folders. Silent folders still organize eligible arrivals after the configured grace period, even when a schedule is enabled.

Scheduled runs skip **Manual**, **Suggest** and **Paused** folders. For a Manual folder, use **Organize Now** to review and approve files when you choose. Suggest also requires approval.

## Grace period and safety

In public Mouzi 0.2.1, a scheduled pass bypasses the grace period. The same applies to operations you approve through **Organize Now**.

Scheduled passes respect built-in file exclusions, the folder's `.mouziignore` and enabled rules in priority order. They apply file-lock checking when **Check file lock** is enabled.

Review checks for locked files when it prepares the preview and again before applying approved operations, even if **Check file lock** is off.

Do not schedule a run for a time when another application regularly writes unlocked temporary files into the watched folder. Add a `.mouziignore` pattern where necessary.

## Mouzi must be running

The scheduler is part of the desktop application. It does not install a separate system service or wake a powered-off computer. Leave **Start with system** enabled if schedules should run after login.
